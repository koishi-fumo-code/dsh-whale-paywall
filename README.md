# 鲸元收费与商场（dsh-whale-paywall）

给 DSH 的一批常用动作加上「鲸元」计费——**纯模拟，不产生任何真实费用**。次数或鲸元不够时会弹出一个收费提示，点「充值」就能进设置里的「商场」买礼包。

支持 DSH 自带的全部 8 种界面语言（中/英/日/德/西/法/葡/俄），换台电脑、换个语言都能正常认按钮。

## 装到别人的电脑上

三种方式，任选一种。

**① 本地目录（最简单，开发用）**

把这个文件夹整个拷到对方电脑，然后在 DSH 里：**插件 → 添加插件 → 安装现有插件**，填该文件夹的绝对路径。

**② 打好的包**

```bash
pnpm pack        # 生成 dsh-whale-paywall-0.1.0.tgz
```

把 `.tgz` 拷给对方，同样在 **插件 → 添加插件** 里填 tgz 的路径（或 `file://` 地址）。

**③ 发布到 npm / Git**

```bash
npm publish            # 发布后对方填 dsh-whale-paywall
```

装完在 **插件** 页把 `dsh-whale-paywall` 打开即可，**不用改任何配置文件**——包里的 `cordis.patch.yml` 会自己插入。

### 装完怎么确认

- 设置面板里多出「商场」一格
- 点「新会话」会弹收费提示
- 余额文件在 `$DSH_HOME/whale-paywall.wallet.json`（首次进入自动创建，初始 50 鲸元）

### 换语言也没问题

插件不写死中文，而是拿 DSH 自带的多语言文案去比对按钮。支持：简体中文、English、日本語、Deutsch、Español、Français、Português、Русский。

## 收费项目

| 功能 | 单次价格 |
|---|---|
| 新建会话 | 6 鲸元 |
| 归档会话 | 1 鲸元 |
| 下载插件 | 12 鲸元 |
| 进入设置 | 1 鲸元 |
| 启用插件 | 1 鲸元 |
| 联网搜索 | 1 鲸元（`web_search` / `web_fetch`） |
| 切换模型 | 1 鲸元 |

**扣费顺序：有次数先用次数，没次数再扣鲸元，都不够才拦。**
（这是使用者确认的规则——买礼包相当于提前把次数囤好。）

**只有「进入设置」这一次收费。** 进去之后在设置里点任何一项（切到商场、改开关、看模型列表）都**不再扣钱**。

## 商场

位置：**设置 → 商场**（左侧导航最后一格）。

| 礼包 | 价格 | 内容 |
|---|---|---|
| 新手礼包 | 16 鲸元 | 3 次新建会话 · 9 次归档 · 1 次下载插件 · 3 次联网搜索 · 1 次切换模型 · 1 次启用插件 |
| 新建会话礼包 | 30 鲸元 | 6 次新建会话 |
| 归档礼包 | 6 鲸元 | 10 次归档 |
| 下载插件礼包 | 60 鲸元 | 10 次下载插件 |

商场页顶部是当前鲸元余额，中间是**七个功能各自剩余的次数**（为 0 时显示红字和单次价格），下面是礼包列表。**初始有 50 鲸元**，礼包按钮不会被禁用——钱不够时会自动补差额再买。

页面底部还有「充值（模拟）」几个按钮和「重置钱包」，方便反复试玩。

## 两个细节

- **进入设置要收费，但「充值」按钮直接放行进商场、不收费。** 否则余额为 0 时进不去设置、也就买不了礼包，会死锁。
- 充值成功后，刚才被拦下的那个动作会**自动补做**（新建会话、归档等），不用再点一遍。

## 弹窗绝不会把你锁住

收费弹窗是一层盖满全屏的浮层，所以专门按「拿它没辙也得能继续用」来设计：

- 遮罩层 `pointer-events: none`，只有中间那张卡片能点 —— **不会吞掉整页的点击**
- 外面包了 React 错误边界：卡片渲染一旦抛异常，立刻清空队列并自动关闭
- 任何弹窗最多显示 **25 秒**自动消失，`Esc` 也能关掉
- 余额读不到时一律**放行**，不会因为接口故障把功能全锁死

## 数据存在哪

`$DSH_HOME/whale-paywall.wallet.json`（Windows 一般是 `C:\Users\<你>\.dsh\whale-paywall.wallet.json`）。Host 半和浏览器半读写的是同一份文件，删掉它就回到**初始 50 鲸元 / 0 次数**。

## 关掉之后

卸载本插件后所有收费与弹窗立刻消失，钱包文件留在原地不会删（下次装回来还能接着用）。
